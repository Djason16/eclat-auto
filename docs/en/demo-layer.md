# Demo layer

**English** · [Français](../fr/couche-de-demo.md)

Éclat Auto has no server and no database: the whole life of the site happens in the visitor's browser, with the rules
a real application would have.

## Data

| Data | `localStorage` key | Starting data |
| --- | --- | --- |
| Catalog (services, options, vehicles) | `eclat-auto:catalog` | `src/lib/content/catalog.ts` |
| Bookings | `eclat-auto:bookings` | `src/lib/demo/seed.ts` |
| Accounts | `eclat-auto:accounts` | demo customer and admin |
| Availability (hours, blocked slots) | `eclat-auto:availability` | opening hours of the workshop |
| Messages | `eclat-auto:messages` | a few sample messages |
| Session | `eclat-auto:session` | signed-in person |

Storage is in `src/lib/demo/storage.ts`; starting data in `src/lib/demo/seed.ts`. A version (`eclat-auto:version`)
resets the data when their format changes.

## Actions

Screens never write directly: they call actions (`src/lib/stores/actions/`) that check then save, and answer with the
`{ success, message, errors }` shape of the APIs generated by DC Scaffold.

- `sessionActions`: sign in, sign up, sign out, profile, documents, account deletion. Passwords are stored as SHA-256 hashes.
- `bookingActions`: price and length of a request (`quote`), booking creation (really free slot, several one-hour slots
  for a long service), cancellation up to 24 hours before, statuses.
- `adminActions`: roles, account deletion (demo accounts are protected), prices, hours, blocked slots, messages.
- `demoActions`: loading, saving and reset.
- `uiActions`: notifications, confirmation and payment windows, guided tour.

A small simulated delay (`simulateLatency`) makes waiting visible, as with a real server.

## What never happens

- No e-mail is sent: the booking confirmation shows a preview of the e-mail.
- No payment: the card window accepts `4242 4242 4242 4242` and declines `4000 0000 0000 0002` without contacting any
  provider; no number is stored.
- No request to another site: no online map, no analytics, no external font.

## Reset

"Remettre à zéro", in the banner at the top of every page, clears the `eclat-auto:` keys and reloads the starting data,
after a confirmation. The booking in progress is cleared too.
